Part 1Controller droplet, Ansible install, fleet key.
Part 2Two clients, one per cloud, each with the controller's public key for user ubuntu and ports 22 and 80 reachable.
Part 3Passwordless SSH from the controller to both: hostnames print with BatchMode=yes.
Parts 4 and 5Inventory and playbook; run twice, the second run reports changed=0; both IPs serve the NGINX welcome page.
Clean updestroy-lab2.sh: droplet, GCP VM (and rule), Azure resource group.

Why this shape: the controller holds the only private key, so the clients never need credentials for each other; the inventory is the single source of truth for what is managed; the same playbook works on both clouds because Ansible speaks SSH and apt, not a cloud API. Swap DigitalOcean for a laptop or a GitHub Actions runner and nothing else changes.
