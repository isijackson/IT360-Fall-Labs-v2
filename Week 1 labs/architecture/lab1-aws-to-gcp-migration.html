Week 1 Lab 1 (AWS variant): Virtual machine migration, AWS to Google Cloud

Infrastructure architecture. Source: an Ubuntu 22.04 Apache web server on EC2 in us-east-2. Target: the same server, byte for byte, on Google Compute Engine. AWS side driven from the console's CloudShell (or the laptop with an access key); GCP side from the laptop with gcloud, qemu-img and GNU tar.

Build (Part 1)Key pair, security group, instance, Apache. Checkpoint: HTTP 200 on the EC2 IP.
Capture (Part 2)Make the OS cloud-neutral, drop caches, freeze the root, qemu-img -T none to raw, compare superblocks (live = copy), e2fsck the copy, compress to qcow2.
Transfer (Part 3)Download, verify checksum, remove the link, convert to raw, tar with the oldgnu format, upload to the bucket.
Launch (Parts 4 and 5)Image from the bucket, VM from the image, firewall rule, HTTP 200 on the GCP IP, the AWS marker file served from GCP.
Clean up (Part 7)rollback-lab1.sh: terminate the instance, delete the volume, security group and key pair; delete the GCP VM, image and bucket.

Dashed boxes are network scope. Bold boxes are the migrated workload. The -aws suffix on the GCP names lets this variant and the Azure variant run side by side in one project. Data path: EC2 root volume to raw (frozen, direct I/O) to qcow2 to laptop to raw to tar.gz to Cloud Storage to Compute Engine image to VM boot disk.
